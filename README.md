# MCU Timeline Sandbox

Every Marvel film and series on one tree (Yggdrasil): 24 universes in Marvel's official story order, with watch tracking, search (Ctrl/Cmd K) and your own branches. Static site: plain HTML, CSS and JavaScript, no build step, no backend, no tracking. Progress is saved only in the visitor's own browser (localStorage).

Run locally: open `index.html`, or `python -m http.server` in this folder.
